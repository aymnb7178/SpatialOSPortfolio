# SpatialOS Portfolio

Bilingual portfolio for **Aymen Abdurabu Al Erwi**, an IT student building practical projects in Python, data analytics, automation, Arabic AI, computer vision, and IT support.

## Highlights

- Responsive Arabic/English interface with language switching
- Project showcase with links to GitHub work
- Skills, experience, contact links, and social profiles
- Lightweight static site: no backend, database, or secret keys required
- Local assets included for reliable rendering

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — complete portfolio page and client-side interactions
- `aiman-logo.jpg` — personal logo
- `aiman-portrait.jpg` — profile portrait

## Deployment

This project can be deployed through GitHub Pages using the `main` branch and the root (`/`) folder.
